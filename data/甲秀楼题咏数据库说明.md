## 印本影像

影像保存在项目根目录的 `facsimiles/` 下，SQLite 中仅写项目相对路径。PDF 若含可独立提取的单页图像，优先保存其原始码流；DJVU 与 IIIF 则按公开服务可取得的原像素页或最高成功尺寸解码、下载。需要通用浏览时另存同像素无缩放 PNG，不用插值放大冒充高清。

| 指标 | 数量 |
| --- | --- |
| 原始档案图（archival-original） | 11 |
| 无损访问副本（access-copy-lossless） | 13 |
| 其他来源原图或全页图 | 15 |
| 查找未果记录 | 20 |

每幅影像同时保存 `pixel_width`、`pixel_height`、`file_bytes`、`sha256`、扫描页和印刷页，便于数字人文项目做文件校验、IIIF转换或OCR流水线。平面目录另见 `jiaxiu_facsimiles_manifest.csv`。

`relation_scope` 把“直接题咏”与同址缘起、区域前史、相邻建筑群明确分开：

| 代码 | 含义 | 作品数 |
| --- | --- | --- |
| strict_jiaxiu | 直接题咏甲秀楼 | 41 |
| site_origin | 建楼缘起、鳌矶或同址初建文献 | 2 |
| nearby_prebuild | 建楼前南明河邻近地点作品 | 2 |
| adjacent_complex | 浮玉桥、翠微园等相邻建筑群 | 1 |

因此，“数据库最早记录”不必等同于“最早直接题咏甲秀楼”。检索或引用前应先选定范围。

## 查询示例

1. 按年代查看直接题咏，并区分创作时间与首次发表：

```sql
SELECT title, authors, date_original, year_start, year_end,
       first_publication_date, authenticity_status
FROM v_chronology
WHERE relation_scope = 'strict_jiaxiu';
```

2. 找出引用前需要特别说明的争议归属、残篇或节录：

```sql
SELECT title, authors, authenticity_status, completeness,
       transcription_status, source_citations
FROM v_works_full
WHERE authenticity_status <> 'confirmed'
   OR completeness <> 'complete'
ORDER BY year_start, title;
```

3. 查看每件作品的底本、页码定位和证据说明：

```sql
SELECT w.title, s.title AS source_title, ws.role, ws.locator,
       ws.is_primary, ws.evidence_note, s.url
FROM works AS w
JOIN work_sources AS ws ON ws.work_id = w.work_id
JOIN sources AS s ON s.source_id = ws.source_id
ORDER BY w.year_start, w.title, ws.is_primary DESC;
```

4. 取得作品对应的本地印本图像相对路径：

```sql
SELECT w.title, a.authors, fi.image_path, fi.scan_page, fi.print_page,
       fi.pixel_width, fi.pixel_height, fi.sha256
FROM work_facsimiles AS wf
JOIN works AS w USING (work_id)
LEFT JOIN v_work_authors AS a USING (work_id)
JOIN facsimile_images AS fi USING (image_id)
ORDER BY w.year_start, w.title, wf.sequence;
```

## 关键限制

- 这是有来源约束的研究型语料库，不宣称穷尽所有甲秀楼相关作品；新增材料应继续保留底本、页码和录入状态。
- 四类 `relation_scope` 不可混为一谈：`nearby_prebuild` 只能回答同片区前史，不能当作甲秀楼建成后的直接题咏；统计直接题咏时应筛选 `strict_jiaxiu`。
- `year_start` / `year_end` 表示创作或事件年代判断，`first_publication_date` / `first_publication_year` 表示目前可证的首次发表；来源自身出版年另存于 `sources.publication_year`。
- 当前有 7 件作品缺少可确定的创作起年，5 件记录了首次发表信息；排序中的空年份不应被解释为作品更晚。
- 当前有 6 件标作残篇或节录，1 件归属有争议，引用时应同时查看 `completeness`、`authenticity_status` 与来源证据。
- 影印本、OCR 和现代转录之间可能存在异体字、俗字、缺字与断句差异。数据库保留录入文本及其显式残缺标记，不依据语意静默补字；待校文字通过 `transcription_status`、`notes` 和 `text_variants` 说明。
- `facsimile_images.image_path` 统一相对于项目根目录，而不是相对于 SQLite 文件目录；移动数据库时应连同 `facsimiles/` 目录一起移动。
- 当前有 20 条逐来源影印查找未果记录；它们表示公开可下载原印本尚未取得，不表示作品或来源不存在。
